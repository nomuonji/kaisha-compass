# Editorial policy

## 1. 一次情報を最優先する

法律・税務・社会保険・行政手続では、可能な限り以下を最初に置く。

- 法務省 / 法務局
- e-Gov
- 国税庁
- 厚生労働省
- 日本年金機構
- 日本政策金融公庫
- 中小企業基盤整備機構
- その他の所管行政機関

## 2. 民間解説は「理解補助」として扱う

freee、弥生、Money Forward、SmartHR、金融機関、士業メディア等は、
一次情報の代替ではなく、初心者が制度の全体像を理解するための補助教材として登録する。

## 3. 学習価値のある専門解説を編集する

Kaisha Compassの主な価値は「何を、いつ、どの順番で学ぶか」の設計。専門解説を無条件に量産せず、原典の正確さ・体系性・読みやすさを揃えた記事だけを掲載する。

会社法・商業登記法の司法書士試験向け教材 `/company-law/` は、専用の静的記事群として編集する。各記事に根拠条文・説明・具体例・誤答しやすい論点・確認問題・一次資料リンクを設ける。内容が条文の説明を超えて個別の登記先例・手続を断定する場合は、法務省・法務局等の一次資料を個別に照合する。

AI生成のみで試験の出題傾向・判例・先例を断定しない。編集日と現行法を法的に校閲した日を混同しない。解説は法律相談や登記申請書作成の代替でない旨を示す。

## 4. 更新性を重視する

制度改正がある領域では、リンク先の日付と適用年度に注意する。
年度依存の教材には将来的に `validAsOf` を追加する。

## 5. ケース会社は教材の接着剤

仮想会社はゲームではない。
バラバラの専門知識に「なぜ今これを読むのか」という文脈を与えるために使う。

## 6. 実務ケース教材の編集方針

`/practice/` は「将来自分で会社を設立・運営する人」の実務理解を主目的とする。既存の仮想会社（株式会社コンパスワークス）を共通の題材とし、単なる届出一覧や法条引用集にはしない。

各ケースに、起こりうる具体的な問題、実務で考える順序、残すことを検討する書類、会社法・関連法令の切り分け、ありがちな誤解、答えのある確認問題、公式資料を必ず用意する。行動を要求するチェックリストではなく学習用の論点一覧として書く。法定義務と実務上の推奨を混同しない。

- 会社法上の決議・代表権・株式・登記と、法人税・労働法・民法・融資実務の規律を混同しない。
- 税務・保険・登記の期限や金額は適用時点に依存する。公式一次資料の現行性を確認する。
- 一人会社、非公開会社、取締役会非設置会社等の前提が変わると結論が変わることを示す。
- 原典リンクは読者が根拠を確かめる出口。実務の順序と意味はサイト内で理解できるようにする。
- 記事の編集日を、すべての条文・通達の現行性を精査した保証日と表現しない。
- 新しい記事は既存25件との重複を避け、ケースの具体性・参考書類・有用な判断を増やす場合だけ公開する。
