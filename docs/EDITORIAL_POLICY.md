# Editorial policy

## 1. 一次情報を最優先する

法律・税務・社会保険・行政手続では、可能な限り以下を最初に置く。

- 法務省 / 法務局
- e-Gov
- 国税庁
- 厚生労働省
- 日本年金機構
- 日本政策金融公庫
- 中小企業基盤整備機構
- その他の所管行政機関

## 2. 民間解説は「理解補助」として扱う

freee、弥生、Money Forward、SmartHR、金融機関、士業メディア等は、
一次情報の代替ではなく、初心者が制度の全体像を理解するための補助教材として登録する。

## 3. 自前の専門解説を増やしすぎない

Kaisha Compassの主な価値は「何を、いつ、どの順番で学ぶか」の設計。
法的・税務的な結論を独自に断定する記事量産を目的にしない。

## 4. 更新性を重視する

制度改正がある領域では、リンク先の日付と適用年度に注意する。
年度依存の教材には将来的に `validAsOf` を追加する。

## 5. ケース会社は教材の接着剤

仮想会社はゲームではない。
バラバラの専門知識に「なぜ今これを読むのか」という文脈を与えるために使う。
